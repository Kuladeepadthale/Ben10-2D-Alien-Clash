# Combat timing batch 14.4

Updated playback for Four Arms, Diamondhead, XLR8, Upgrade, Stinkfly,
Ghostfreak, Cannonbolt and Wildvine. The alien details page identifies these
characters with **Animation 14.4 · combat timing**.

This is a playback refinement using existing native character cels. It does
not replace character designs, add newly drawn frames, or reproduce TV footage.
The remaining roster has not received this pass.

- Preparation stays visible until the attack's release.
- Sustained powers retain the contact pose throughout the active interval.
- Multi-hit melee retracts between contacts, with individual timing per alien.
- Four-pose strikes show recoil and then settle through recovery.
- Rolling, rushing and airborne slam animations keep their dedicated paths.
- Heatblast and the detailed Wildmutt, Grey Matter and Ripjaws renderers are
  preserved, along with walking, damage, targeting, rewards and saved progress.

Validation: `node ci/check-animation144.cjs`. Covers all eight timing profiles,
two/three/four-frame clips, phase boundaries, repeated melee contacts, held
beams, six existing native metadata sets, defensive-state fallbacks, and script
ordering. Cannonbolt and Wildvine use metadata generated by the existing cel
export pipeline; their timing profiles are checked here. Device visual testing
and a new Android build are still required before calling this a release.
