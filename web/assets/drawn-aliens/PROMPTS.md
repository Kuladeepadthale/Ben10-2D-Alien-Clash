# Drawn alien animation prompts

Generated using the built-in image-generation tool with each classic portrait as a design reference. These are newly generated key poses, not extracted TV animation. Source images were re-encoded to PNG without changing decoded RGBA pixels. Runtime rectangles and anchors are stored in `manifest.json`; the original images are retained.

## Layout quality control
Nominal grid cells are not used as cut lines. Full-atlas connected silhouettes are measured so outstretched arms, wings and tails remain intact. A few overlapping or extra drawings are remapped to complete neighboring keys from the same action family: Upgrade's merged punch keys reuse its clean wind-up/follow-through; Wildmutt's merged ultimate keys reuse its complete pounce keys; Ghostfreak's long lash uses the same complete reach for adjacent keys. Four Arms and Upgrade contain an extra drawing in their final row, which is omitted from playback. Thus there are 48 timeline slots per alien, with some reused keys rather than 48 unique usable drawings. All original generated pixels remain in the PNGs.


## Runtime isolation
Each playback rectangle also has a run-length silhouette mask measured from the primary connected character shape, with a one-pixel antialias margin. The game creates and caches clean frame canvases on demand, discarding other characters' detached fragments from within a wide rectangle. Original PNG pixels remain unchanged on disk. The frame cache is limited to 96 entries. Complete PNG checksums, chunk CRCs and inflated image sizes are verified in CI before building.
