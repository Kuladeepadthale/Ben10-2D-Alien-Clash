# Heatblast classic model-to-sprite pilot — 2.0

The rigged body is authored in Blender with a faceted crimson-rock silhouette, pale-yellow molten seams, connected joint volumes, finger bones and two-bone IK. The actual bundled original classic illustrated head is retained as a head texture decal to preserve its recognisable face/flame design. This is a hybrid character, not a wholly hand-drawn or fully volumetric flame head. Existing original-art credits still apply. It is classic-inspired, not an exact copy of television animation, and uses no Nekki/Cascadeur animation assets or code.

The phone plays 256 unique baked frames: idle 8, forward 48, backward 48, jump 16, guard 12, hit 8, knockdown 16, normal strike 20, fireball 20, flame jet 20, eruption 16 and ultimate 24. All share the same rig, camera, source scale and floor. Bind-pose surface coordinates keep lava patterns attached to the skin. Grounded target travel is linear during stance, with smooth Hermite swing motion. Runtime phase follows actual movement distance; backward movement has its own clip. Guard release plays the baked preparation backwards. Strike anticipation reaches the release pose continuously at the impact boundary. Wrist/hand positions are projected into emitter metadata.

Four losslessly encoded 1536 × 1536 WebP sheets contain antialiased 192-pixel cells downsampled from 224-pixel renders. Source generation, conversion and packing are in ci/heatblast-model. No 3D rig runs on the phone. The previous Heatblast atlas is retained as a historical asset but is no longer selected by this renderer. Other aliens, gameplay values and the 1.9 interface are unchanged.

Review: rendered 660 frames across 22 seconds using the production sprite renderer; inspected locomotion and combat contact sheets, including guard, strike wind-up/release/recovery, fireball, flame jet, eruption, ultimate and knockdown. Corrected a hidden far leg in the initial resting stance and anchored the lava pattern to bind coordinates. Final pixel checks found zero detached secondary silhouette components and no clipped frame. Planted-foot tracking residual was 0.428 source pixels per baked step (maximum). Locomotion, Diamondhead image playback and menu navigation tests passed. This is a pilot; Android device performance and appearance have not been measured here.
